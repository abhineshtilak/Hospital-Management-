# AfroCare Hospital Management

A modern, responsive, static hospital management dashboard built with plain HTML, CSS and JavaScript.

## Features
- Dashboard overview
- Patient CRUD-lite management
- Appointment scheduling
- Doctor directory
- Ward and bed status board
- Billing and invoice tracking
- Browser `localStorage` persistence
- JSON data export and demo reset
- Responsive phone and desktop layout
- No React, backend or database required

> Demo/admin interface only. Do not use real patient/medical data. Browser storage is not appropriate for production healthcare records.
